# Spotnet 3.0.9.0

## English

- **Community settings:** A new Settings > Community page brings together the Spotnet community servers, newsgroups, moderation lists and Newznab indexer. View list counts, refresh lists, change the refresh interval, and import or export a community profile. Existing community defaults are preserved.
- **Moderation support:** Configure moderator keys and optional verification of signed moderation lists. Communities can require valid signatures; signature checking is not enabled by default.
- **Remote away from home:** Create a Cloudflare Quick Tunnel from the Remote settings or pairing window and connect through an HTTPS link without port forwarding. The required component downloads on first use. The link is temporary and can change when the tunnel restarts; Spotnet and the PC must remain running.
- **Remote login and pairing:** Choose local Wi-Fi or Cloudflare when pairing by QR code. Logging out now revokes the session token on the server, authentication changes take effect without restarting Remote, and spot images require a valid token when authentication is enabled.
- **WebP images:** Open WebP spot images and choose .webp files or image/webp URLs when adding a spot. Decoding uses the Windows WIC codec; a missing codec produces an installation hint. WebP is converted to JPEG before posting for compatibility with other clients, which removes transparency.
- **Legacy telemetry removed:** Removed Google Analytics reporting for startup, shutdown, opened spots and updates, together with its device identifier.
- **Promotional links removed:** Missing-article download errors no longer link to a provider promotion, and new comments no longer receive an automatic promotional footer. The wrong-password action remains available.
- **Maintenance:** Updated the About information and project documentation, standardized the source folder as src/Spotnet, and corrected shared-state interference in regression tests.

## Nederlands

- **Community-instellingen:** Een nieuw paneel Instellingen > Community bundelt de Spotnet-communityservers, nieuwsgroepen, moderatielijsten en Newznab-indexer. Bekijk lijstaantallen, werk lijsten bij, stel het bijwerkinterval in en importeer of exporteer een communityprofiel. De bestaande community blijft de standaard.
- **Ondersteuning voor moderatie:** Configureer moderatorsleutels en optionele controle van ondertekende moderatielijsten. Communities kunnen geldige handtekeningen verplicht stellen; deze controle staat standaard uit.
- **Remote buiten de deur:** Maak vanuit de Remote-instellingen of het koppelvenster een Cloudflare Quick Tunnel en verbind via een HTTPS-link zonder port forwarding. Het benodigde onderdeel wordt bij het eerste gebruik gedownload. De link is tijdelijk en kan veranderen wanneer de tunnel opnieuw start; Spotnet en de pc moeten aan blijven.
- **Remote-inloggen en koppelen:** Kies bij koppelen met een QR-code tussen lokale wifi en Cloudflare. Uitloggen trekt nu het sessietoken op de server in, gewijzigde authenticatie-instellingen werken zonder Remote opnieuw te starten en spotafbeeldingen vereisen een geldig token wanneer authenticatie aanstaat.
- **WebP-afbeeldingen:** Bekijk WebP-spotafbeeldingen en kies .webp-bestanden of image/webp-URL's bij het toevoegen van een spot. Het lezen gebruikt de Windows WIC-codec; bij een ontbrekende codec verschijnt een installatiehint. Voor compatibiliteit met andere clients wordt WebP vóór het posten naar JPEG omgezet, waardoor transparantie vervalt.
- **Oude telemetrie verwijderd:** Google Analytics-rapportage over opstarten, afsluiten, geopende spots en updates is verwijderd, samen met de bijbehorende apparaatidentificatie.
- **Promotielinks verwijderd:** Downloadfouten door ontbrekende artikelen linken niet meer naar een providerpromotie en nieuwe reacties krijgen geen automatische promotietekst meer. De actie om een verkeerd uitpakwachtwoord te wijzigen blijft beschikbaar.
- **Onderhoud:** Het Over-venster en de projectdocumentatie zijn bijgewerkt, de broncodemap heet nu src/Spotnet en conflicten door gedeelde toestand in regressietests zijn opgelost.

Application version / Applicatieversie: **3.0.9.0**. Windows x64; .NET 10 included / inbegrepen.
