# Spotnet 3.0.1: readable menus in dark and light mode

This patch fixes light-on-light menu text in Modern Dark and improves menu-state contrast in Classic Light.

## Fixed

- Main toolbar menus and nested submenus now consistently use the Spotnet theme instead of Windows Aero or UI-library default templates.
- Right-click menus for spots, filters, comments, and downloads no longer inject the old light-only Aero dictionary.
- Menu backgrounds, text, keyboard shortcuts, arrows, checkmarks, and separators use dedicated theme colors.
- Hover, open, keyboard-focus, checked, and disabled states stay readable. Disabled rows no longer fade their text to near-invisibility.
- Existing main menus update when switching between light and dark mode; newly opened context menus use the current palette.

## Install or upgrade

Download **Spotnet-3.0-x64-Setup.exe** and run it under your usual Windows account. It upgrades an existing installer-based 3.0 installation, closes Spotnet safely, keeps your profile, makes a verified backup, and updates your Spotnet Desktop/Start Menu shortcuts. Fresh installation and compatible legacy-profile migration remain supported.

Requires Windows 10/11 x64 and .NET Framework 4.7.2+. Missing WebView2 is installed using Microsoft's bootstrapper and needs internet access. The Spotnet package remains **unsigned**; Windows may show an unknown-publisher/SmartScreen warning. A SHA-256 checksum is included in the release assets.

See the [installation/migration guide](https://github.com/Cyclone47/spotnet-2.0/blob/main/docs/INSTALLER.md) for profile compatibility, backup recovery, shortcut scope, and limitations. Active legacy download queues are not imported. Existing profile data and downloaded files are retained.

- Isolated actual installer testing covers fresh installation, repeated upgrade, shortcut replacement/restoration, verified backups, and uninstall retaining personal data.
