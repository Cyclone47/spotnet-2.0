# Spotnet 3.0.3: a rebuilt connect dialog, a verified provider list, and Dutch that works

This release replaces the provider selection screen, corrects a provider list that had not been
touched since 2014, and fixes a Dutch interface that had never actually worked.

## Fixed

- **The Dutch interface now appears in Dutch.** Spotnet 2.0 shipped `nl\Spotnet.resources.dll`, but
  the reconstruction recovered only the text dumps of it, so no satellite assembly was ever built
  and every Dutch installation silently fell back to the English table. The satellite is rebuilt.
- Three strings had no Dutch translation and three Dutch strings could never be looked up. Both
  tables are now key-for-key identical, enforced by a test.
- Setup passes the language it ran in to a new profile, so choosing Nederlands starts Spotnet in
  Dutch. A migrated profile keeps whatever language it already stated.
- The connect dialog follows the application theme. It previously hardcoded a light blue gradient,
  and marked invalid fields with a pale yellow fill that was unreadable under ModernDark.

## Provider list

Every entry was re-checked by opening the socket and reading the NNTP greeting banner, which is the
only evidence that the far end is really a news server.

- **KPN v1 and KPN v2 are removed.** All four of their hosts answer
  `500 Vanaf 1 mei 2026 zijn we gestopt met Usenet-toegang via deze server`.
- **5 Euro Usenet and SnelNL moved from port 80 to 563.** Port 80 accepts the TCP connection and
  then never sends a greeting, so connecting hung until it timed out instead of failing.
- Seven providers were correct as shipped and are unchanged.
- Fifteen were added, favouring Dutch and EU providers: Tweaknews, Usenet.Farm, Hitnews, XLned,
  Bulknews, Cheapnews, Newshosting, UsenetServer, Easynews, Astraweb, Giganews, NewsDemon,
  Frugal Usenet, Newsgroup Direct and Supernews.

Twenty-four providers, twenty-seven distinct endpoints, all answering.

## Changed

- The provider dropdown is searchable. Type part of a provider name or a server address and the
  list narrows; entries are grouped into Nederlandse and Internationale providers and each row
  shows the server it will connect to.
- The dialog is larger and resizable, laid out in sections, with the account fields separated from
  the advanced server settings.
- The "if you have no account yet, click HERE" affiliate line is gone.

## The provider list is now published

The list lives in [`providers.json`](../../providers.json) in the repository and is fetched when the
connect dialog opens, so a provider that shuts down or changes ports can be corrected without a new
release. Editing instructions are in [PROVIDERS.md](../PROVIDERS.md).

This list determines which servers the dialog offers, and users type their Usenet credentials into
whichever one they pick, so it is treated as untrusted input rather than configuration:

- The built-in list stays authoritative until a fetched copy validates in full. The dialog never
  waits on the network and never comes up empty because a download was truncated or an edit was bad.
- A single invalid entry rejects the whole document; a partially applied list is how one bad row
  would hide among two dozen good ones.
- The cached copy is revalidated on every load rather than trusted because it is local.
- HTTPS only, redirects not followed, with size and timeout limits. Servers must be plain DNS names
  and ports must be one of the four Usenet ports.
- Nothing is applied to an account that is already configured. Only the options offered change.

`tools/Test-Providers.ps1` validates the file against those same rules and reads every server's
greeting; it runs in CI on any change to the list and weekly on a schedule.

## Install or upgrade

Download **Spotnet-3.0-x64-Setup.exe** and run it under your usual Windows account. Choose English
or Nederlands at startup. The installer upgrades an existing installer-based 3.0 installation, keeps
your profile, makes a verified backup, and updates your current-user Spotnet Desktop and Start Menu
shortcuts. Fresh installation and compatible legacy-profile migration remain supported.

Your configured provider is not changed by this update. If you are on KPN, that server has stopped
serving Usenet and you will need to pick another provider.

Requires Windows 10/11 x64 and .NET Framework 4.7.2+. Missing WebView2 is installed using
Microsoft's bootstrapper and needs internet access. The Spotnet package remains **unsigned**;
Windows may show an unknown-publisher or SmartScreen warning. A SHA-256 checksum is included in the
release assets.

See the [installation and migration guide](https://github.com/Cyclone47/spotnet-3.0/blob/main/docs/INSTALLER.md)
for profile compatibility, backup recovery, shortcut scope, and limitations. Active legacy download
queues are not imported; existing profile data and downloads remain intact.

## Verification

- **177/177 automated tests pass** on the x64 Release host.
- Every provider endpoint in `providers.json` was probed and returned a valid NNTP greeting.
- The published catalogue's rejection paths are pinned individually: bad ports, hosts that are not
  plain DNS names, unknown schema versions, duplicate entries, names carrying control characters or
  bidirectional overrides, oversized lists, and truncated files. Each falls back to the built-in
  list rather than emptying the dialog.
- The Dutch satellite assembly is checked for the exact resource name `ResourceManager` looks up,
  and both resource tables are compared key-for-key.
- The dialog was driven end to end against the live published file: adding a provider to the JSON
  made it appear without a rebuild, and every malformed variant fell back to the built-in list.

Application version: **3.0.3.0**. This remains the community reconstruction based on Spotnet 2.0,
not an official upstream release.
