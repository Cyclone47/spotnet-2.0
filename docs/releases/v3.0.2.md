# Spotnet 3.0.2: Dutch Setup and visible preparation progress

This patch improves the first-install and upgrade experience. It includes the 3.0.1 menu contrast fixes.

## Fixed

- Selecting **Nederlands** at Setup startup now translates Spotnet's custom wizard text. Previously only Inno Setup's built-in heading, buttons, and labels changed language while the large custom welcome body and migration pages stayed English.
- Dutch translations cover the welcome screen, installation detection, data/profile and preferences choices, custom file/folder pages, Ready summary, progress/status messages, errors, completion text, shortcut handling, and uninstall prompts.
- Lengthy work before file extraction no longer leaves the generic Preparing page looking frozen. A dedicated progress page identifies the active stage: safely closing Spotnet, handling WebView2, or copying and verifying the profile.
- Progress-page cleanup uses a `finally` block, so errors and retries cannot leave the wizard stuck on that page.

## Install or upgrade

Download **Spotnet-3.0-x64-Setup.exe** and run it under your usual Windows account. Choose English or Nederlands at startup. The installer upgrades an existing installer-based 3.0 installation, keeps your profile, makes a verified backup, and updates your current-user Spotnet Desktop/Start Menu shortcuts. Fresh installation and compatible legacy-profile migration remain supported.

Requires Windows 10/11 x64 and .NET Framework 4.7.2+. Missing WebView2 is installed using Microsoft's bootstrapper and needs internet access. The Spotnet package remains **unsigned**; Windows may show an unknown-publisher/SmartScreen warning. A SHA-256 checksum is included in the release assets.

See the [installation/migration guide](https://github.com/Cyclone47/spotnet-2.0/blob/main/docs/INSTALLER.md) for profile compatibility, backup recovery, shortcut scope, and limitations. Active legacy download queues are not imported; existing profile data and downloads remain intact.

## Verification

- **111/111 automated tests pass** on the x64 Release host.
- Installer regressions require a Dutch translation for every English custom message and verify that all custom-message references exist.
- Progress regression checks that the visible page is created, updated for profile preparation, and always hidden in `finally`.
- The actual 3.0.2 Setup completed fresh install, repeat upgrade, shortcut replacement, verified backup, and uninstall/shortcut restoration in Dutch inside an isolated workspace root. It did not touch the real Spotnet profile or shortcuts.

Application version: **3.0.2.0**. This remains the community reconstruction based on Spotnet 2.0, not an official upstream release.
