# Spotnet 3.0.4: provider dialog hotfix

This patch fixes the two first-use provider-dialog bugs reported after 3.0.3.

## Fixed

- **The dialog now fits low-resolution and scaled desktops.** Its initial and maximum dimensions
  are capped to the available Windows working area. It can be resized down to 480 x 360 logical
  pixels, and the content scrolls while the header and Connect/Cancel footer remain available.
- **Provider search no longer changes the text while typing.** Entering a search such as `news`
  keeps those characters and the caret in the edit box instead of cycling through matching provider
  names.
- **Searching no longer raises `ArgumentOutOfRangeException`.** The provider collection is now
  filtered only after WPF has completed its internal ComboBox edit. Stale selection state is cleared
  before refreshing the list, avoiding the invalid collection index shown by 3.0.3.
- Enter, Escape, clicking a provider and abandoning a search still commit or restore the expected
  provider without clearing credentials for the currently configured provider.

## Install or upgrade

Download **Spotnet-3.0-x64-Setup.exe** and run it under your usual Windows account. Setup upgrades
an existing installer-based Spotnet 3.0 installation, keeps the profile, makes a verified backup and
updates current-user shortcuts. Fresh installation and compatible legacy-profile migration remain
supported.

Requires Windows 10/11 x64 and .NET Framework 4.7.2+. The package is **unsigned**, so Windows may
show an unknown-publisher or SmartScreen warning. A SHA-256 checksum is supplied with the release.

## Verification

- **179/179 automated tests pass** on the x64 Release host.
- New regression checks pin the resizable small-screen layout and ensure filtering is dispatched
  outside the editable ComboBox's synchronous text-change event.
- The installer is built from the tagged source and smoke-tested for both English and Dutch fresh
  installs, upgrades, profile backups, shortcuts and uninstall behavior.

Application version: **3.0.4.0**. This remains the community reconstruction based on Spotnet 2.0,
not an official upstream release.
