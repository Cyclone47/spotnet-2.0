# Spotnet 3.0.11.0

A cleanup release. Nothing you use every day should look different; what changed is
underneath, and most of it is code that had quietly stopped working.

## English

**Safer spot view**
- The spot themes no longer load jQuery 1.8.3 and Bootstrap 2.2.0. Both date from 2012 and
  carry known cross-site scripting flaws (CVE-2020-11022, CVE-2020-11023, CVE-2015-9251 and
  CVE-2016-10735), while the page they render is filled with titles, descriptions, user
  names and comments written by strangers on Usenet. The parts the themes actually used —
  the tab switcher and the accordion — have been rewritten without them. The styling is
  untouched.
- A content security policy now limits where a spot page may talk to. Apple's iTunes is the
  only outside address the themes call, and it is the only one still allowed.

**Third-party integrations moved and switched off by default**
- Settings has a new section, **External integrations**, holding the Newznab indexer and an
  OMDb key. Both start out empty, and empty means off.
- The Newznab default pointed at a server that no longer answers and shipped with an API key
  baked into the program. Both are gone. If you had entered your own indexer it moves across
  untouched; searches no longer wait on a server that will not reply.
- The film and series information panel asked OMDb for data without a key, which that
  service has required since 2017 — so it had been silently empty for years. Enter a key and
  it works again; leave it empty and the panel says where to set one instead of staying blank.

**Downloads**
- New option: remove chosen file types once post-processing finishes, for the leftovers that
  come with a download. Off unless you fill it in.

**Repairs**
- `build.bat` reported a failure after every successful build.
- The alpha update channel pointed at a folder on a former contractor's machine.

## Nederlands

Een opruimversie. Aan de buitenkant zou niets anders moeten ogen; wat er veranderde zit
eronder, en het meeste daarvan was code die allang niet meer werkte.

**Veiliger spotweergave**
- De spotthema's laden jQuery 1.8.3 en Bootstrap 2.2.0 niet meer. Beide stammen uit 2012 en
  dragen bekende XSS-lekken (CVE-2020-11022, CVE-2020-11023, CVE-2015-9251 en
  CVE-2016-10735), terwijl de pagina die zij opbouwen juist vol staat met titels,
  omschrijvingen, gebruikersnamen en reacties van onbekenden op Usenet. Wat de thema's er
  werkelijk van gebruikten — de tabwissel en het accordeon — is zonder die bibliotheken
  opnieuw geschreven. De opmaak is ongemoeid gebleven.
- Een content security policy begrenst met wie een spotpagina nog mag praten. Apple's iTunes
  is het enige externe adres dat de thema's zelf aanroepen, en het enige dat toegestaan blijft.

**Externe integraties verplaatst en standaard uit**
- Instellingen heeft een nieuw kopje **Externe integraties**, met de Newznab-indexer en een
  OMDb-sleutel. Beide beginnen leeg, en leeg betekent uit.
- De Newznab-standaardwaarde wees naar een server die niet meer antwoordt, met een
  API-sleutel die in het programma zelf zat. Beide zijn verdwenen. Had u een eigen indexer
  ingevuld, dan verhuist die ongewijzigd mee; zoekopdrachten wachten niet langer op een
  server die niet reageert.
- Het film- en serie-informatieblok vroeg gegevens op bij OMDb zonder sleutel, terwijl die
  dienst er sinds 2017 een vereist — het blok was dus al jaren stil leeg. Vul een sleutel in
  en het werkt weer; laat u het leeg, dan zegt het blok waar u die instelt in plaats van leeg
  te blijven.

**Downloads**
- Nieuwe optie: gekozen bestandstypen verwijderen zodra de nabewerking klaar is, voor de
  restjes die met een download meekomen. Staat uit tot u hem invult.

**Reparaties**
- `build.bat` meldde een fout na elke geslaagde build.
- Het alpha-updatekanaal wees naar een map op de machine van een oud-inhuurontwikkelaar.
