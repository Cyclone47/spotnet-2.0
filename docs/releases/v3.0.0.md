# Spotnet 3.0 for Windows x64

The first installable 3.0 release of this reconstructed and modernized Spotnet client, based on the C#/WPF Spotnet 2.0.0.284 application. This is a community reconstruction, not an official upstream release.

## Download and requirements

Download **Spotnet-3.0-x64-Setup.exe** from the release assets. **Spotnet-3.0-x64-Setup.exe.sha256** contains its SHA-256 checksum.

- Windows 10/11 on x64 hardware; .NET Framework 4.7.2 or later.
- Setup installs for the current Windows user. Run it using the account that owns your existing profile.
- Microsoft Edge WebView2 is installed if missing; that step needs internet access.
- The Spotnet installer is **unsigned**. Windows may show an unknown-publisher/SmartScreen warning. Microsoft prerequisite downloads are publisher-signature checked.

## Installation and migration

- Fresh installation with provider configuration on first launch.
- Detection of compatible old Spotnet 2.x installations, data folders, and preferences, with a wizard to select the source.
- Graceful Spotnet shutdown before migration. Setup waits for it to close and stops if it cannot; it does not force-kill the application.
- Verified profile copies into `%LOCALAPPDATA%\Spotnet3\Data`, including SQLite databases and WAL/SHM companions. Original application files and source profiles are retained.
- Stable per-user settings, verified pre-upgrade backups, and personal-data retention on uninstall.
- Existing current-user Desktop and Start Menu Spotnet `.lnk` launchers are updated to 3.0 in place, including legacy Squirrel-based and previous 3.0 links. Fresh installations create both launchers. Unrelated/uninstall links are preserved.
- Original launchers are backed up. Uninstall restores them or removes newly created links only when the user has not edited them.
- Installed builds no longer use the legacy Squirrel update feed; install a newer Setup package to update.

## Modernization highlights

- x64 application, managed yEnc decoder, SQLite interop, browser loader, and LibVLC runtime.
- Awesomium replaced by Microsoft Edge WebView2 for its former web-tab integrations.
- Meta.Vlc replaced by LibVLCSharp; SQLite and several managed libraries updated.
- Safer ZIP extraction using framework compression, improved TLS defaults, parameterized database operations, and XML hardening at identified boundaries.
- SQLite WAL/durability improvements, repair/rebuild tooling, and fixes for the reported `PRAGMA synchronous` startup error and fresh-database initialization.

## Scope and known limitations

- Migration supports compatible C# Spotnet 2.x/3.x profiles, not arbitrary Spotnet 1.x/VB formats. Active download queues are not imported; finish or export queued work before upgrading. Existing downloads remain in their original locations.
- Shortcut updates cover this user's Desktop and Start Menu `.lnk` files. Shared/all-users links, taskbar/Start pins, ClickOnce `.appref-ms` launchers, and network/junction/symlink locations are not automatically changed.
- Spot-detail/comment HTML still uses the Windows WebBrowser/MSHTML control. Not every browser path has moved to WebView2.
- External `phpar2.exe`, `UnRAR.exe`, and `7za.exe` utilities remain 32-bit child processes; the main application and in-process runtimes are x64.
- Real-provider, graphics/video, and broader historical-profile/account acceptance testing remain necessary. This release is not a claim of a complete security audit.

## Validation

108 automated tests pass under the x64 Release test host. An isolated actual Setup test covers fresh installation, required payloads, old/current/Squirrel shortcut replacement, unrelated-link preservation, repeat upgrade with a verified backup, and uninstall restoring shortcuts while keeping synthetic personal data.
