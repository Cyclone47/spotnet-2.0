# Spotnet 3.0.10.0

## English

- **Spot image close fixed:** A spot image expanded to full size can now be closed again by pressing Escape or clicking anywhere outside the image.

## Nederlands

- **Sluiten van spotafbeelding hersteld:** Een spotafbeelding die op volledig scherm is vergroot, kan nu weer worden gesloten door op Escape te drukken of buiten de afbeelding te klikken.

Application version / Applicatieversie: **3.0.10.0**. Windows x64; .NET 10 included / inbegrepen.
