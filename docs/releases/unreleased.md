# Grote opruimbeurt

Nog niet uitgebracht.

- **Oude NZB-zoekfunctie verwijderd:** Spotnet gebruikt de oude Binsearch-zoekfunctie niet meer. Bij een spot zonder NZB-verwijzing verschijnt direct een melding, zonder herhaalde zoekpogingen.
- **Geen tijdelijke download bij een ontbrekende NZB:** Een spot zonder NZB-verwijzing wordt niet eerst aan de downloadlijst toegevoegd om daarna weer te verdwijnen.
- **Beschikbare NZB's blijven bruikbaar:** Ook wanneer een spot nog oude metadata bevat, gebruikt Spotnet een aanwezige NZB-verwijzing. Gewone NZB's, versleutelde NZR's en Newznab-downloadlinks blijven ondersteund.
